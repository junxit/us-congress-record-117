# Vote on Guzman Nomination (Executive Calendar)

**Speaking:** Wyden, Ron (W000779) [D-OR], Durbin, Richard J. (D000563) [D-IL], Thune, John (T000250) [R-SD], Menendez, Robert (M000639) [D-NJ]

```
                       Vote on Guzman Nomination

  Mr. WYDEN. Madam President, I would ask unanimous consent that the 
scheduled vote occur immediately.
  The PRESIDING OFFICER. Without objection, it is so ordered.
  The question is, Will the Senate advise and consent to the Guzman 
nomination?
  Mr. WYDEN. I ask for the yeas and nays.
  The PRESIDING OFFICER. Is there a sufficient second?
  There appears to be a sufficient second.
  The clerk will call the roll.

necessarily absent.
```
